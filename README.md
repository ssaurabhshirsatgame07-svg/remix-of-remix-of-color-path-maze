# Remix of Remix of Color Path Maze

Build a polished original mobile-first puzzle game inspired by a color-path maze. Use React/TypeScript with a canvas-based renderer. The game should have a portrait layout, beige background, a top HUD with hearts, timer, and level indicator, and a bottom control area with zoom controls and a hint button. Core gameplay: trace colorful maze paths using mouse/touch swipes, follow directional arrows, detect invalid moves, subtract lives on mistakes, show level complete and game over states, and support restart. Start with a playable first level and clean architecture so more handcrafted levels can be added later. Make the visuals feel close to the provided screenshot but original, smooth, and production-quality.
